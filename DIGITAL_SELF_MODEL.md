# DIGITAL SELF — Los 5 YO

## Modelos (separados, nunca mezclados automáticamente)

| Estado | Naturaleza | Fuente | Confianza |
|---|---|---|---|
| YO PASADO | hechos históricos del gemelo | EXPERIENCE + evidencia | alta (OBSERVED con evidencia) |
| YO PRESENTE | estado actual consolidado | genome actual | alta (versionado) |
| YO FUTURO | **proyección**, no hecho | Future Agent (escenarios) | explícitamente baja, etiquetada |
| YO POTENCIAL | **proyección** de desarrollo | Future Agent (capacidades latentes) | baja, hipotética |
| YO SOMBRA | contradicciones, riesgos, patrones no deseados | Pattern Agent + reflexión | media, INFERRED |

## Metadatos obligatorios por modelo

fuente, timestamp, confianza, procedencia, versión, evidencia, relación con YO PRESENTE (diff explícito).

## Reglas

1. **Proyecciones no son hechos**: YO FUTURO/POTENCIAL se presentan siempre como escenarios ("si mantienes este patrón, entonces..."), con condiciones explícitas.
2. **YO SOMBRA sin diagnóstico**: representa tensiones y patrones que requieren reflexión; jamás convierte inferencia psicológica en diagnóstico clínico. Lenguaje: "patrón observado" no "eres X".
3. **Reconciliación consciente**: cuando YO SOMBRA contradice YO PRESENTE (ej. valor declarado vs patrón observado), el sistema genera CONTRADICTION insight — no resuelve silenciosamente.
4. **Caducidad de proyecciones**: toda proyección se re-evalúa contra EXPERIENCIA nueva; divergencia proyección-realidad alimenta el Evolution Engine (aprendizaje del modelo predictivo del gemelo).
